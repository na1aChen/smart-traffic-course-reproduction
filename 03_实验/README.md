# 实验区说明

每个实验使用唯一 ID。主结果只能从本目录的配置、日志、预测和指标生成。

计划结构：

```text
configs/
logs/
predictions/
checkpoints/
figures/
实验总表.csv
失败与异常记录.md
```

实验总表字段将在阶段 1 按主模型输出格式确定。不得只记录最终 mAP 而遗漏配置和命令。

## 当前基线

- 实验 ID：`BASE_YOLOV10N_TT100K45_S2026`
- 训练目录：`baseline_yolov10n\train`
- 配置：YOLOv10-N，640，batch 8，40 epochs，SGD，seed 2026
- 最佳验证轮次：第 39 轮，mAP50 `0.521620`，mAP50-95 `0.400000`
- 测试集：mAP50 `0.500520`，mAP50-95 `0.375802`
- 正式日志：`logs\BASELINE-001`
- 测试原始预测：`baseline_yolov10n\test_eval\labels`

## 阶段 4：P2-001

- 单因素：P2/4 浅层高分辨率分支与 P2 检测头
- 配置：640、batch 8、40 epochs、SGD、seed 2026
- 最佳验证轮次：第 38 轮，mAP50 `0.508650`，mAP50-95 `0.387250`
- 测试：mAP50 `0.499295`，mAP50-95 `0.372658`
- small mAP50-95：`0.256332`，高于基线的 `0.212520`
- 结论：局部小目标机制得到支持，但总体 AP、large AP 和时延代价不利
- 最终主模型：否；`BASELINE-001` 继续作为最终主模型

完整权重、逐图预测、训练批预览和大日志保留在本地；Git 追踪配置、指标、曲线、审计 JSON 和小型证据文件，以避免仓库体积失控。

## 阶段 5：稳健性

- `BASELINE-002-S2027`：基线第二个 seed；
- `P2-002-S2027`：P2 第二个 seed；
- `BASELINE-BUDGET48-S2026`：仅增加训练轮数的预算对照。

两次 seed 的 P2 small AP 均高于对应基线；48 epoch 对照提高了总体指标，但 small AP 仅为 `0.222883`，低于 P2 两 seed 均值 `0.254124`。最终主模型仍为 `BASELINE-001`。
