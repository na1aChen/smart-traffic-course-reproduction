# 阶段 2 运行器说明

本目录只承载阶段 2 的基线运行与证据生成逻辑。官方源码目录 `../源码/yolov10` 保持原样，不修改训练器、损失函数或推理逻辑。

## 环境

使用阶段 1 已锁定的虚拟环境：

```powershell
<PROJECT_ROOT>\02_代码\环境\venv\Scripts\python.exe
```

## 子命令

- `probe`：执行 1 轮小比例训练，比较 512/640 输入与 batch 4/8 的显存、耗时和可运行性，同时作为训练链路 smoke test。
- `train`：只运行一次正式基线。随机种子固定为 2026，测试集不参与训练或模型选择。
- `evaluate`：加载验证集选出的 `best.pt`，在测试集上执行一次最终评估，保存原始预测，并用 `pycocotools` 从原始预测复算 mAP。

正式顺序：

```text
probe -> 锁定配置 -> train -> evaluate -> 阶段总结
```

所有运行均从阶段 1 的本地 Hugging Face 权重快照加载，不依赖临时网络下载。
