# 交通标志多目标检测个人课程项目

本目录用于执行《智能+交通》大作业 2。阶段 0–7 已完成并通过验收，下一阶段为PPT与答辩。

项目采用“一个阶段一个门槛”的推进方式。每个阶段只有在证据齐全并通过验收后才进入下一阶段。单个会话只推进一个或两个相邻阶段，不在一个会话中同时完成实验、报告和答辩材料。

交付范围分为两层：基础要求必须全部完成；高阶要求“目标识别 + 交通流量预测”作为受时间箱约束的拓展目标，在基础证据达到门槛后尽可能完成。高阶拓展不能挤占基线复现、错误分析和改进实验的必需时间。

最终截止时间已确定为 **2026-11-22**。每个阶段完成时，必须先写出对应的中文阶段总结 Markdown，才能把该阶段标记为通过。

## 核心原则

所有报告和 PPT 中的数字必须能追溯到实验总表、原始日志或输出文件。未完成多种子验证的结果只能写成“单次探索性结果”。未做对照实验的设计只称为“尝试”或“适配”，不称为“创新已生效”。
