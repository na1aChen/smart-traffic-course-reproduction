# TT100K交通标志小目标检测复现与验证性改进

本仓库是《智能+交通》大作业2的公开复现材料，记录YOLOv10-N在TT100K-45类数据上的基线复现、小目标错误诊断、P2高分辨率分支实验、第二seed、48轮预算对照，以及检测结果到TA-iTransformer的离线模块级联。

## 主要结果

|实验|seed|测试mAP50|测试mAP50-95|small AP|large AP|
|---|---:|---:|---:|---:|---:|
|BASELINE-001|2026|0.500520|0.375802|0.212520|0.558442|
|P2-001|2026|0.499295|0.372658|0.256332|0.467160|
|BASELINE-002-S2027|2027|0.494270|0.371632|0.214047|0.550859|
|P2-002-S2027|2027|0.494465|0.371687|0.251915|0.474918|
|BASELINE-BUDGET48-S2026|2026|0.510513|0.384359|0.222883|0.580088|

最终主模型为BASELINE-001。P2分支在两个seed中均提高small AP，但总体AP、大目标AP和推理时延代价更差，因此保留为负结果与权衡实验。

## 复现步骤

1. 递归克隆仓库并初始化官方YOLOv10子模块。

```powershell
git clone --recurse-submodules https://github.com/na1aChen/smart-traffic-course-reproduction.git
```

2. 从TT100K官方页面下载2016标注包，并按照`02_代码/工具`中的数据准备脚本生成固定划分。
3. 从官方YOLOv10发布页获取预训练权重，放置路径以`03_实验/configs`和训练脚本中的相对目录约定为准。
4. 依次运行基线、错误诊断、P2、第二seed和48轮预算对照。
5. 使用冻结测试预测复算mAP，并运行各阶段审计脚本核对主表与图表。

## 数据与权重说明

TT100K原始图像和压缩包受数据体积与许可限制，不直接存入仓库。YOLOv10预训练权重、训练检查点和完整逐图预测不进入公开仓库。仓库保留数据划分清单、配置、指标、图表、日志摘要、原始预测校验值、阶段审计和报告正文。

## 复现边界

离线模块级联使用图像编号顺序构造检测代理序列，仅用于接口和数据流验证。TT100K图像不是连续时间序列，检测对象与PEMS08传感器不存在真实时空对应，因此MSE、MAE和单窗口预测差不能解释为端到端交通态势预测性能。
