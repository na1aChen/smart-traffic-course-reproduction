# 图1与图5的制作说明

## 一、Napkin.ai操作

1. 打开`https://www.napkin.ai/`，登录或注册账号。
2. 新建一个Napkin，将对应提示词粘贴到正文。
3. 选中提示词，点击`Generate visual`或旁侧的生成按钮。
4. 图1优先选择`Timeline`、`Roadmap`或`Flow`，图5优先选择`Flowchart`或`Process`。
5. 配色使用白底、蓝绿灰三色，不使用渐变和阴影。
6. 导出`PNG`或`SVG`。Word中按比例插入，建议宽度15.2cm至15.8cm。

## 二、图1 Napkin提示词

```text
制作一张中文研究路线图，包含六个连续阶段：
01数据与来源锁版：TT100K-45类、YOLOv10；
02基线复现：BASELINE-001；
03错误诊断：尺寸、类别、固定工作点；
04P2单因子：小目标高分辨率分支；
05稳健性验证：两seed、48轮预算；
06-5S离线联调：检测结果到流量预测。

布局采用两行三列或纵向路线，阶段01到03为“证据建立”，阶段04到06为“验证与边界”。箭头必须按顺序连接。风格简洁、学术、白底，蓝绿灰配色，适合A4课程报告。
```

## 三、图5 Napkin提示词

```text
制作一张纵向中文流程数据流图，节点依次为：
检测结果（类别、置信度、检测框）
适配器（按image_id顺序等频分箱，累计置信度并标准化）
固定输入（96×170）
TA-iTransformer（严格加载既有checkpoint）
预测输出（96×170）

在适配器侧增加一个虚线边界说明：
valid_as_time_series=false；
图像ID顺序不代表真实时间；
本图只验证接口、数据流与可复现性。

风格简洁、学术、白底，蓝绿灰配色，强调这是离线模块级联，不是端到端交通态势验证。
```

## 四、Mermaid备用源文件

- `图1_研究路线.mmd`
- `图5_模块级联数据流.mmd`

可将代码粘贴到`https://mermaid.live/`，选择`Actions -> PNG`或`Actions -> SVG`导出。
