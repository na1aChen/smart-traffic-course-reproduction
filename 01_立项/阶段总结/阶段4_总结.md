## 一、阶段目标与边界

目标是只改变一个可测因素：为 YOLOv10-N 增加 P2/4 浅层高分辨率特征和 P2 检测头，检验它是否改善 TT100K 小目标检测。

本阶段没有同时改变损失函数、数据增强、类别权重或优化器；没有用 P2 的测试结果反向调参；测试集仅在新模型验证完成后评估一次。

## 二、实际完成的工作

### 2.1 预注册与架构开关

- 冻结单因素、训练预算、验证指标、停止条件和失败处理方式。
- 基线 YAML 与 P2 YAML 分离，保证基线路径未被改变。
- P2 检测尺度为 P2/P3/P4/P5，stride 为 `4/8/16/32`。
- P2 参数量为 2,937,544；基线为 2,724,590；增加 212,954（+7.816%）。

### 2.2 启动 smoke

- 640×640、batch 8。
- 110 张训练图、14 个真实训练 batch。
- 训练 23.547 秒，loss 全部有限。
- 峰值分配显存 3.1987 GiB，峰值保留显存 4.8086 GiB。
- smoke 未运行 test。

### 2.3 正式训练

- 40 个 epoch，640 输入，batch 8，SGD，seed 2026。
- 最佳验证轮次：38。
- 最佳验证 mAP50：0.508650；mAP50-95：0.387250。
- 恢复段峰值分配显存 3.2108 GiB，峰值保留显存 4.9355 GiB。
- 训练过程出现一次计划断电，从第 28 轮后的 `last.pt` 成功恢复第 29–40 轮。

### 2.4 最终评估

- 新模型 `best.pt` 冻结后，测试集只执行一次推理。
- 保存 3,071 个原始预测文件，共 307,100 条候选预测。
- YOLOv10 内置与 pycocotools 复算的 mAP 差均小于 0.001。

## 三、核心结果

### 3.1 测试集

| 指标 | BASELINE-001 | P2-001 | 差值 |
| --- | ---: | ---: | ---: |
| mAP50 | 0.500520 | 0.499295 | -0.001225 |
| mAP50-95 | 0.375802 | 0.372658 | -0.003144 |
| mAP small | 0.212520 | 0.256332 | +0.043813 |
| mAP medium | 0.443357 | 0.438532 | -0.004825 |
| mAP large | 0.558442 | 0.467160 | -0.091282 |
| AR100 | 0.722476 | 0.759036 | +0.036560 |

验证集也出现相同机制方向：

- small mAP50-95：0.247625 → 0.289397，增加 0.041772；
- 总 mAP50-95：0.400000 → 0.387250，下降 0.012750。

### 3.2 固定工作点错误结构

置信度 0.25、匹配 IoU 0.50：

| 错误类型 | BASELINE-001 | P2-001 | 差值 |
| --- | ---: | ---: | ---: |
| TP | 4,440 | 4,679 | +239 |
| 错类 | 930 | 1,041 | +111 |
| 近定位失败 | 11 | 0 | -11 |
| 漏检 | 2,325 | 1,986 | -339 |
| 背景误检 | 441 | 544 | +103 |
| 重复检测 | 969 | 1,018 | +49 |

P2 确实减少了漏检，但同时增加错类、背景误检和重复检测，最终没有提高总体 AP。

### 3.3 工程代价

- PyTorch 单图推理时间：4.200 ms → 12.181 ms，约 2.9 倍。
- 参数量增加 7.816%。
- GFLOPs 工具对 `v10Detect` 返回 0，未得到可信 FLOPs；该限制已记录，不能伪造数值。

## 四、结论

**机制判断：** P2 高分辨率信息对小目标 AP 有正向作用，验证集和测试集都支持该方向。

**总体判断：** P2-001 的总体 mAP50、mAP50-95 均低于基线，验证集总体降幅超过预注册的 0.005 容许阈值，大目标 AP 明显下降，推理时延约增至 2.9 倍。

**决策：** 不将 P2-001 作为最终主模型。最终基线继续使用 `BASELINE-001`；P2-001 作为“机制局部有效但总体权衡不利”的负结果保留。
