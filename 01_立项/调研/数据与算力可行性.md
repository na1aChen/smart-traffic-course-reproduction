## 三、类别选择原则

作业要求至少 10 类。建议优先采用文献中常见的完整可用类别集合；如果官方划分或工具已按“训练实例数不少于一定阈值”给出类别集合，则直接采用并在报告中引用来源。只有在无法使用标准集合时，才自行删类。

若必须自行筛类：

1. 只根据训练集实例数排序，不使用验证集或测试集频率。
2. 阈值和类别列表在训练前写死并保存为 JSON。
3. 验证集与测试集不能因为某类实例少而被重新抽样。
4. 类别 ID 必须建立固定映射，所有实验共用。
5. 删除某类标注后，原始实例不能继续被当作该类的正样本；必须检查剩余标注是否会产生“未选类被当背景”的偏差。
6. 如果筛类导致这种偏差明显，宁可使用所有标准类别并加类别平衡手段，也不要随实验动态改变类别空间。

风险：第二张截图中的“红灯、绿灯、转向灯”是通用交通场景示例，不能直接假定为 TT100K 的类别名。具体类别必须以官方标注文件为准。

## 四、划分与泄漏控制

优先使用数据集或主论文采用的固定 train/val/test 划分。若官方包没有直接提供训练用划分，则使用可复现的固定规则，在第一次训练前生成并冻结：

1. 按图像 ID 划分，不按裁剪框划分。
2. 固定随机种子、排序方式、比例和脚本版本。
3. 同源街景或近重复图像不得跨 train/val/test。
4. 随机翻转、亮度、噪声、雨雾、裁剪只能作用于训练集。
5. 过采样和类别权重只使用训练集统计。
6. 验证集用于早停和超参数选择；测试集只用于最终报告。
7. 合成退化测试集另行固定，不能与训练增强参数反复调优。
8. 保存每张图片归属和最终类映射的 SHA-256。

## 五、实验预算

以下为保守估算，不是实测：

| 实验 | 初始配置 | 目的 | 预计量级 |
| --- | --- | --- | --- |
| 环境 smoke test | YOLOv10-N，imgsz 512，batch 4，2 个短 epoch | 验证 CUDA、数据读取、训练和保存链路 | 分钟级 |
| 显存与吞吐 probe | 固定 100 至 500 张图，比较 512/640 与 batch 4/8 | 选定正式 batch 和尺寸 | 10 至 30 分钟 |
| 正式基线 | 640，AMP，batch 由 probe 确定，最大 epoch 数和早停训练前写死 | 得到测试集主指标 | 数小时量级，需实测 |
| 单因子改进 | 与基线相同的数据、划分、seed、epoch、输入尺寸和优化预算 | 只测一个机制 | 约为一次基线耗时 |
| 多种子 | 主比较至少 3 个 seed（理想） | 均值、标准差和波动 | 按配置数倍增 |

如果单 epoch 实测时间导致无法完成计划，应同步缩减 epoch、类别集合或 seed 数，并在报告中标注“单次探索性结果”。不能只对改进组缩短训练。

## 六、最小可完成实验矩阵

| 实验 ID | 配置 | 必须回答 |
| --- | --- | --- |
| `E00-env` | CUDA 与模型 smoke test | 环境、数据、权重和保存链路是否可用 |
| `E01-base` | 官方或同配方基线，seed 42 | 基线指标、时延、参数量和错误分布 |
| `E02-diag` | 复用 E01 原始预测做诊断 | 错误来自长尾、小目标、退化场景还是其他机制 |
| `E03-A` | 只打开由 E02 证据支持的因子 A | A 是否有可复核变化 |
| `E04-ctrl` | 同容量或随机/无语义对照 | 增益是否只是更多参数或训练预算 |
| `E05-A+B` | 仅在时间允许时组合 | 组合是否优于单因子；若不能拆分则明确说明 |
| `E06-seeds` | 基线与关键配置多 seed | 均值、标准差、失败运行与稳定性 |
| `S01-integration` | 检测 JSON 与流量预测离线联调 | 高阶模块是否可运行；数据拼接边界是否诚实 |

## 七、降级路径

| 情况 | 降级动作 | 结论强度 |
| --- | --- | --- |
| GPU 环境无法建立 | 停止正式训练，先修复环境和数据链 | 不产生模型性能结论 |
| 8 GiB 显存 OOM | 先降到 batch 4，再到 512 输入或梯度累积 | 记录变化，不与 640 配置混比 |
| 完整训练超时 | 使用预注册的 10 至 12 类固定子集或缩短统一 epoch | 只写当前预算下结果 |
| 无法完成 3 seed | 至少完成同预算单 seed 对照 | 只写“单次探索性结果” |
| 无第二数据集 | 在固定合成退化集或留出划分做鲁棒性检查 | 不声称泛化性 |
| 高阶数据无法时空对齐 | 只做模块级离线联调和架构说明 | 不声称端到端态势预测已实现 |
