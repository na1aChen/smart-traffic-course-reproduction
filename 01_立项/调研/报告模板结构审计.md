## 四、字体与标题层级

| 角色 | 模板事实 |
| --- | --- |
| Normal | 10.5 pt，两端对齐；西文默认 Times New Roman，中文默认宋体 |
| 章标题 | `List Paragraph` 自定义样式，16 pt、加粗；段落带一级大纲级别和自动编号 |
| 二级标题 | 使用 Normal 段落直接格式，黑体 14 pt，如 `1.1 研究背景` |
| 封面主标题 | 黑体 26 pt、加粗、居中 |
| 封面字段 | 宋体 14 pt为主，部分下划线为直接格式 |
| 页眉 | 宋体 12 pt、居中 |
| 页脚 | 宋体 12 pt、居中 |
| 目录标题 | 实际渲染为蓝色直接格式；这是模板原状，不应擅自改成其他版式 |

模板没有使用标准 `Heading 1` 或 `Heading 2` 样式。章标题通过自定义段落样式和一级大纲级别进入目录，二级标题主要使用直接格式。目录字段带 `\u` 开关，因此可以读取大纲级别，但刷新后必须检查缓存条目和实际页号。

样式审计发现 62 个直接格式文本运行和 25 个直接格式段落。这些直接格式是模板现状，不应做全局“样式归一化”，否则会破坏封面和标题外观。

## 五、固定章节结构

模板只提供六章骨架，没有正文段落、摘要、关键词或独立参考文献页。

1. 研究背景与意义
   - 1.1 研究背景
   - 1.2 研究意义与现状
2. 模型介绍
   - 2.1 模型概述
   - 2.2 核心网络结构

3. 实验训练结果
   - 3.1 数据集与预处理
   - 3.2 实验环境设置
   - 3.3 实验结果与分析
4. 模型改进与实验
   - 4.1 模型改进创新
   - 4.2 改进创新实验结果
5. 拓展实验内容
   - 5.1 新增内容介绍
   - 5.2 系统总体设计思路

模板未提供“摘要”“关键词”“参考文献”等独立章节，也没有可见的页数上限。后续是否增加这些章节，应再次核对课程要求，不能仅凭常见论文格式自行插入。

## 七、保真约束

最终报告制作和终验必须遵守：

1. 从原模板复制，不从空白 DOCX 重建。
2. 原模板保持字节不变，并复核 SHA-256。
3. 保留 A4 页面、边距、两个分节和封面首页不同设置。
4. 保留校名、校徽、封面表格、页眉、页脚和页码字段。
5. 保留章标题字体、字号、编号和二级标题黑体 14 pt。
6. 新增正文采用模板 Normal 风格体系，中文宋体、西文 Times New Roman；正文默认约 10.5 pt，不擅自压到更小字号。
7. 新增图片必须嵌入文档，不依赖外链；图题、表题和正文引用齐全。
8. 表格数字必须来自冻结实验总表，表头可读，单元格不得裁切。
9. 目录更新后条目、编号和实际页号一致。
10. 不整体清理模板中的直接格式和自定义样式。
11. 每一个实质性编辑批次结束后重新渲染，检查全部页面。

## 八、LibreOffice 复验

用户补齐 LibreOffice 后，已使用 documents 技能的 `render_docx.py` 对原模板重新渲染：

- `soffice.exe`：`C:\Program Files\LibreOffice\program\soffice.exe`
- 复验目录：`01_立项\模板审计_LibreOffice复验`
- 输出：`page-1.png` 至 `page-4.png`
- 结果：4 页全部生成，正文页、页眉、页脚和页码正常

渲染命令的日志读取线程出现一次 GBK 解码警告，但命令退出码为 0，4 张 PNG 均生成且可查看。阶段 7 仍需在相同环境下对最终 DOCX 重新执行全套渲染。

复验发现一个模板差异：封面在 LibreOffice 下出现顶部横线，而先前辅助渲染没有该横线。该横线可能来自首页不同页眉或页眉段落边框。最终报告副本需要在不破坏模板其余结构的前提下显式设置空白首页页眉或移除其边框，然后再次渲染确认。原模板不做修改。
