## 可行的高阶最小原型

建议采用模块级离线联调，不伪造端到端连续视频数据：

```text
TT100K 测试图像
  -> 检测模型
  -> 结构化检测结果
  -> 目标计数或交通对象统计快照
  -> 固定格式接口
  -> TA-iTransformer 流量预测
  -> 预测序列与可视化
```

需要额外实现：

1. 检测结果导出器，输出图像 ID、类别、置信度、边界框和统计时间。
2. 检测计数到预测模型输入的适配层。
3. 一个可重复的演示脚本，读取固定输入并产生固定输出。
4. 对接口、来源和拼接方式的说明。

## 关键限制

- TT100K 是交通标志图像数据集，不等同于连续路网流量数据。
- PEMS08 是传感器交通流数据，与 TT100K 图像没有天然的时间或空间一一对应关系。
- 若直接把检测图像排序后当时间序列，只能称为演示性拼接，不能称为真实交通态势预测。
- 更可信的表述是“检测模块与预测模块的可运行系统原型”，而不是“已在真实道路端到端验证”。

## 启动条件

只有基础检测的基线、错误分析和至少一个单因子实验通过门槛后，才启动本原型。若未满足条件，高阶部分只能保留系统设计，不制作带虚假数字的演示页面。
