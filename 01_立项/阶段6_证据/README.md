# 阶段6证据冻结索引

本目录是阶段6的唯一冻结入口。阶段7和阶段8只能引用这里登记的数字、图片和原始证据路径。

## 一、先读文件

- `最终主表.md`：中文主表与统一口径；
- `最终主表.csv`：机器可读的统一数字源；
- `实验证据索引.csv`：实验ID到配置、日志、指标、checkpoint和预测的映射；
- `损失口径登记.csv`：训练、验证和测试损失边界；
- `百分比口径登记.csv`：百分数的分子、分母和比较对象；
- `主图冻结清单.csv`：四张主图的哈希和离线重绘命令；
- `证据SHA256清单.csv`：数据、权重、脚本、日志、预测和证据哈希；
- `数字变更与版本规则.md`：冻结后如何变更；
- `阶段6审计.json`：最终审计结果。

## 二、重绘主图

使用项目虚拟环境执行：

```powershell
02_代码\环境\venv\Scripts\python.exe 02_代码\阶段6\build_stage6_freeze.py --figures-only
```

该命令只读取冻结证据并重绘四张主图，不加载模型、不重新训练、不执行测试推理，也不重算SYS5S级联。

## 三、重新生成登记层

```powershell
02_代码\环境\venv\Scripts\python.exe 02_代码\阶段6\build_stage6_freeze.py --all
02_代码\环境\venv\Scripts\python.exe 02_代码\阶段6\audit_stage6.py
```

`--all` 会同时重绘主图并重新计算所有SHA-256。审计器会核对主表数字、实验路径、损失口径、百分数口径、主图可重绘性和哈希清单。

## 四、冻结边界

- 5S已确定为模块级离线联调原型并通过内部审计；阶段6不重新评估、重做或扩展5S。
- 阶段6不重新训练、不重新测试、不修改既有指标、权重、checkpoint或原始预测。
- 数据、权重、完整日志和原始预测保留在本地，GitHub远端保存路径、摘要、哈希和审计。
