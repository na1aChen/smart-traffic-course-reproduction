## 四、可重复的可靠下载方式

不直接依赖 pip 在安装时下载 2.6 GB 的 Torch wheel。可靠流程如下：

1. 从 PyTorch 官方 wheel 索引确认明确版本、平台标签和 SHA-256。
2. 使用支持断点续传和自动重试的下载器，把 wheel 下载到 `02_代码\环境\wheels`。
3. 下载后先检查精确字节数，再计算 SHA-256；任何一项不一致都停止安装。
4. 使用锁定虚拟环境中的 pip 从本地 wheel 安装，不让 pip 重新选择包源。
5. 安装 Torchvision 时使用 `--no-deps`，避免 pip 把已锁定的 Torch 替换成其他版本。
6. 按官方 requirements 安装其余依赖，固定 NumPy 1.26.4。
7. 运行 `pip check`、CUDA 矩阵乘、官方模型加载和实际推理 smoke test。

一键重装入口：

```powershell
powershell -ExecutionPolicy Bypass -File `
  ".\大作业2\项目\02_代码\环境\setup_gpu_env.ps1"
```

脚本会复用已完整下载的 wheel，并执行上述尺寸和 SHA-256 校验。普通 `pip install torch` 不进入正式环境流程，因为它可能从不同索引选择版本，无法保证与 YOLOv10 官方锁定版本一致。
