# 阶段 2：基线复现实验设计

记录日期：2026-11-08。

## 一、唯一主问题

YOLOv10-N 使用官方模型结构和固定预训练权重，在 TT100K 2016 的 45 类固定划分上，按本机可执行的单卡预算迁移训练后，能否形成指标可复算、测试集未泄漏、误差可继续诊断的可靠基线。

## 二、实验 ID 与职责

| 实验 ID | 用途 | 是否进入主表 |
| --- | --- | --- |
| `SMOKE-001` | 验证数据入口和训练链路可运行 | 否 |
| `probe_20261108_123034_i640_b8` | 真实数据的 640、batch 8 资源和速度探测 | 否 |
| `BASELINE-001` | 固定配置的正式基线训练 | 是 |
| `BASELINE-001-TEST` | 对验证集选出的最佳权重执行一次最终测试 | 是 |

smoke 和 probe 的 mAP 不能作为基线结果，也不能用于模型选择。

## 三、固定配置

| 模块 | 固定值 |
| --- | --- |
| 模型 | YOLOv10-N |
| 输入尺寸 | 640 × 640 |
| batch | 8 |
| 最大 epochs | 40 |
| 优化器 | SGD |
| 初始学习率 | 0.01 |
| 早停 patience | 10 |
| 最后关闭 Mosaic | 5 epochs |
| AMP | 开启 |
| 随机种子 | 2026 |
| GPU | `device=0` |
| DataLoader workers | 0 |
| 数据划分 | train 5,489；val 610；test 3,071 |

## 四、数据职责

- train 只用于参数更新。
- val 只用于每轮验证、`best.pt` 选择和早停。
- test 在训练完全结束后只评估一次，不参与训练、调参、早停或失败重试时的方案选择。
- 最终 test 评估的 YOLOv10 内置指标和 `pycocotools` 复算都固定每图最多 100 个检测框，与标准 COCO `maxDets=100` 对齐。
- 数据集入口只读取 `03_实验\datasets\TT100K\yolo\tt100k.yaml`。
- 测试集原始预测必须保存，再由 `pycocotools` 从原始预测复算指标。

## 五、通过条件

1. 训练进程正常结束或由验证集早停结束。
2. 生成 `best.pt`、`last.pt`、`results.csv`、验证曲线和训练日志。
3. `best.pt` 能重新加载并完成一次测试集评估。
4. 测试集原始预测、COCO 真实值、复算指标和每类指标均保存。
5. YOLOv10 自带指标与 COCO 复算口径可以相互解释。
6. 所有失败运行保留，不覆盖正式基线。
7. 生成中文 `阶段2_总结.md`，并逐项填写阶段 2 验收清单。

## 六、解释限制

- 当前只训练 40 个 epoch，明显少于官方 COCO 的 500 epoch，不能把与论文的数值差异直接归因于模型能力。
- 当前只使用单 seed，本阶段所得是“基线的单次确定运行”，不是多种子均值或统计显著性结论。
- 本阶段不实现类别加权、数据增强改造、结构替换、剪枝、量化或蒸馏；这些留给阶段 3 诊断后决定。
- 本阶段不把测试集分数用于反向选择训练轮次或参数。
