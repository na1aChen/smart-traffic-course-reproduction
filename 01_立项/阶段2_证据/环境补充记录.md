# 阶段 2 环境补充记录

记录日期：2026-11-08。

## 一、变更内容

在阶段 1 已锁定环境中新增绘图依赖：

```text
seaborn==0.13.2
```

安装命令：

```text
02_代码\环境\venv\Scripts\python.exe -m pip install --no-deps seaborn==0.13.2
```

## 二、原因

YOLOv10 上游代码在以下两个位置直接导入 `seaborn`：

- `ultralytics\utils\plotting.py`：标签分布相关图。
- `ultralytics\utils\metrics.py`：混淆矩阵。

首次正式训练启动日志出现：

```text
No module named 'seaborn'
```

若继续缺失，训练可以继续，但混淆矩阵等阶段 2 验收图表会被上游 `TryExcept` 捕获并跳过。该问题只影响绘图，不影响模型结构、损失、优化器、权重或已有训练进程。

## 三、依赖边界

- 使用 `--no-deps`，只新增 `seaborn` 本身。
- 未升级或降级 NumPy、Pandas、Matplotlib、Torch 或 Torchvision。
- 安装后版本：NumPy 1.26.4、Pandas 2.3.3、Matplotlib 3.10.9。
- 安装后 `pip check` 输出：`No broken requirements found`。
- 已在训练进行中安装；下一轮绘图调用会生效，不需要重新开始训练。

## 四、对锁版的影响

`02_代码\环境\environment.json` 保持阶段 1 原样，作为训练开始前的环境快照。本文件仅记录阶段 2 为补齐验收图表而增加的依赖，不得把它误写成阶段 1 已包含 `seaborn`。
